# News Blogs 📰  

A full-stack **news blog application** where users can browse and search for the latest articles from different categories like sports, technology, and world news.  

## 📂 Project Structure  
news-blogs/ 
│── backend/ # Node.js Express server (API) 
│── frontend/ # React (Vite) frontend 
│── README.md


---

## 🚀 Getting Started  

### 1️⃣ Clone the Repository  
```sh
git clone https://github.com/YOUR-USERNAME/news-blogs.git
cd news-blogs
cd backend
npm install

Inside the backend/ folder, create a .env file and add:
PORT=3000
NEWS_API_KEY=your_api_key_here

START THE SERVER
npm start


 Frontend Setup (React + Vite)

 cd ../frontend
npm install
export const API_URL = "http://localhost:3000/news";
npm run dev

✨ Features
✅ Latest news articles from different categories
✅ Search articles by topic
✅ Dark mode support 🌙
✅ Fully responsive design

🛠 Tech Stack
Frontend: React (Vite), TailwindCSS
Backend: Node.js, Express.js
API: NewsAPI
